1. bucket name is already taken before writing your code, use the AWS CLI
------aws s3api head-bucket --bucket YOUR_DESIRED_BUCKET_NAME--------------
aws s3api head-bucket --bucket serverless-etl-s3
*******aws: [ERROR]: An error occurred (404) when calling the HeadBucket operation: Not Found****** ok to use name

2. bucket creation
aws s3api create-bucket --bucket serverless-etl-s3 --region us-east-1
arn:aws:s3:::serverless-etl-s3

3.bucket inside folder as (raw)
*single folder as this
aws s3api put-object --bucket serverless-etl-s3 --key raw/

* multiple folder as this
aws s3api put-object --bucket serverless-etl-s3 --key raw/ && \
aws s3api put-object --bucket serverless-etl-s3 --key silver/ && \
aws s3api put-object --bucket serverless-etl-s3 --key gold/

4.Put file local to aws
aws s3 cp AdventureWorks_Customers.csv s3://serverless-etl-s3/raw/AdventureWorks_Customers.csv
